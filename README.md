# OBSCURA® — Independent Digital Designer Portfolio

Premium interactive portfolio. Conceptual digital atelier.

## Concept

**THE DIGITAL ARTELIER** — design, spatial objects, light and motion as one visual universe.

Cinematic dark minimalism · premium craft · experimental editorial type · sophisticated 3D CGI.

## What’s included (upgraded)

- **Interactive 3D hero** — glass transmission material, chrome rings, floating fragments, mouse parallax, ContactShadows, WebGL fallback
- **Unique project covers** — 8 distinct procedural compositions (geometry, light, accent treatment per case)
- **Filterable gallery** with Framer Motion layout animations
- **Case study pages** with scroll reveals, palette, role, next-project nav
- **About / Services / Contact** with motion, validated form (Zod), clear backend note
- **Scroll parallax** on hero, staggered entrance animations, reduced-motion support
- Fully responsive, keyboard-accessible, semantic HTML

## Stack

- React 19 + TypeScript + Vite
- React Three Fiber + Three.js + Drei
- Framer Motion
- React Router · Zod · Lucide

## Run

```bash
cd obscura
npm install --legacy-peer-deps
npm run dev
```

Build: `npm run build`

## Notes

- All 8 projects are **fictional conceptual studies**.
- Contact form validates and tells the user a backend must be connected.
- 3D uses procedural geometry + PBR / transmission materials (no external GLB required).
- Covers are unique CSS/SVG compositional treatments matched to each project’s art direction.
